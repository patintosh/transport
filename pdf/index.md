      
# Bibliothèque PDF –

Cette section rassemble l’ensemble des documents PDF associés aux différentes catégories du site :
- analyses thématiques,
- articles,
- documents de travail,
- chapitres PDF complets,
- études, rapports, séries temporelles,
- textes comportant notes de bas de page, illustrations et tableaux.

Tous les documents ici conservent **la mise en page originale**, y compris :
- graphiques, figures et images,
- tableaux,
- notes de bas de page,
- équations et références.

## 📌 Pour ajouter un PDF

Placez vos fichiers dans le dossier `pdf/` via :

➡ **Add file → Upload files**  
➡ Choisir vos PDF  
➡ Commit changes

Une fois téléversés, vous pourrez créer les liens dans :
- cette page `/pdf/index.md`
- ou directement dans les sections thématiques (`maritime`, `aerien`, etc.)
