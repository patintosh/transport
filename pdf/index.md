       
# Bibliothèque PDF     

Cette section rassemble l’ensemble des documents PDF associés aux différentes catégories du site :
- analyses thématiques,
- articles,
- documents de travail,
- chapitres PDF complets,
- études, rapports, séries temporelles.

Tous les documents ici conservent **la mise en page originale**, y compris :
- graphiques, figures et images,
- tableaux,
- notes de bas de page.
